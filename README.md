# Sistem Absensi Sekolah (PWA)

Aplikasi Web Responsive & Progressive Web App (PWA) untuk absensi siswa harian dan dashboard monitoring guru.

## Fitur Utama
1. **Sisi Siswa:**
   - Persistent storage identitas siswa (Nama & Kelas tersimpan di local browser).
   - Dynamic Random Motivation Quote.
   - Absensi Realtime (Hadir, Izin, Sakit) beserta lampiran.
2. **Sisi Guru:**
   - Auth Portal Guru.
   - Dashboard monitoring dengan Filter Kelas (X-1 s.d. XII-5).
   - Sorting A-Z, Search Bar, dan Pagination.
   - Manajemen CRUD data absensi.
